### Zhipeng (Mara) Zhu

Analytical chemist (pharma QC and method validation) who builds LLM agents for lab science. Brooklyn, NY.

**Projects**

- **[aliquot-lims](https://github.com/zhipengzhu1-dotcom/aliquot-lims)** is a LIMS and electronic lab notebook ([live demo](https://animated.nitrolims-demo.com)).
- **[hplc-retention-order-predictor](https://github.com/zhipengzhu1-dotcom/hplc-retention-order-predictor)** predicts HPLC retention order from structure. It uses RDKit, pretrained chemprop/SoluteML ensembles and Uni-pKa, with a defined applicability domain that refuses compounds outside it.
- **[ocm-regulatory-agent](https://github.com/zhipengzhu1-dotcom/ocm-regulatory-agent)** answers questions about the New York cannabis laboratory regulations (Claude Agent SDK). Code checks every quoted passage against the source and sends any answer it can't verify back to the model to rewrite.
- **[nitrosamine-lims-agents](https://github.com/zhipengzhu1-dotcom/nitrosamine-lims-agents)** is a LIMS built to 21 CFR Part 11 and ISO/IEC 17025. Three Claude reviewer subagents audit its designs, and a graded eval checks their findings.
- **[lc-pda-simulator](https://github.com/zhipengzhu1-dotcom/lc-pda-simulator)** is an HPLC gradient simulator. It fits two scouting runs, and its predictions are checked against measured retention times.

**How I work:** I use Claude Code with custom subagents and skills, MCP servers, and an issue-driven agentic workflow.
